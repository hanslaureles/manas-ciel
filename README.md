# Manas: Ciel (archived snapshot)

This repository is an early snapshot of Ciel, my bilingual voice copilot, from September 2026. It is kept as it was and is no longer maintained.

Ciel now lives in [LSFM AI HQ](https://github.com/hanslaureles/lsfm-ai-hq): see `ciel_server.py` and `ciel_orchestrator.py` and the "Ciel: the voice copilot" section of its README. The [Ciel case study](https://hanslaureles.vercel.app/case-ciel) describes how it works and how it was measured.

The original README of this snapshot made performance claims that were never measured for this code; they are not repeated here.
